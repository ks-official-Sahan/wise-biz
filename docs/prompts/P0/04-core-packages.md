## Goal
The four packages every module depends on: universal (Node, Hermes/React Native, browser), fully tested, and stable enough that later steps never touch their APIs casually.

## Scope
1. **`@wise-biz/ids`** (universal):
   - `uuidv7()` (monotonic within the same millisecond), `isUuidv7()`, `timestampOf(id)`.
   - `Hlc` hybrid logical clock: `now()`, `receive(remote)`, `compare`, `serialize/parse`; max drift guard (configurable, default 5 min).
   - Randomness via `crypto.getRandomValues` only (RN gets it from `expo-crypto` polyfill later).
2. **`@wise-biz/money`** (universal):
   - **Decision to record (ADR 0005 addendum):** minor units are JS `number` guarded by `Number.isSafeInteger` (2^53 minor units is far beyond any POS amount; avoids bigint cost and JSON pain). DB stays `bigint` (Drizzle `mode: 'number'`).
   - ISO 4217 exponent table (0, 2, 3 decimals), `Money { minor, currency }`, `add/sub/neg/compare`, `multiply(ratio, rounding)`, `percent(bps)`, `allocate(weights)` (remainders distributed deterministically), `splitEvenly(n)`.
   - Rounding modes: half-even, half-up, down, up. Tax helpers: `taxFromExclusive(net, rateBps)`, `taxFromInclusive(gross, rateBps)`, per-line vs per-document strategy.
   - Cash rounding (`roundToIncrement(money, increment)`, e.g. 0.05).
   - `format(money, locale)` via `Intl.NumberFormat`, `parse(str, currency)`.
   - Currency mismatch throws a typed error.
3. **`@wise-biz/errors`**: `DomainError` (code, message, details, httpStatus hint), error code registry (`STOCK_INSUFFICIENT`, `NOT_FOUND`, `IDEMPOTENCY_MISMATCH`, `ENTITLEMENT_REQUIRED`, …), `toProblem(err, requestId)` → RFC 9457 object.
4. **`@wise-biz/contracts`**:
   - Layout: `src/common/*`, `src/<module>/*` (empty folders for P1 modules with README stubs), `src/events/*`.
   - Common schemas: `Uuid7`, `Currency`, `Money` (`minor` safe int + `currency`), `Cursor`, `Page<T>`, `Problem`, `Timestamp` (ISO UTC).
   - Event envelope schema + `defineEvent(type, version, dataSchema)` registry; `listEvents()`.
   - Generators: `pnpm -F @wise-biz/contracts gen` writes `generated/asyncapi.json` from the registry and `generated/jsonschema/*.json`. OpenAPI is generated by the API app later from routes; provide `registerRoute()` types only.
   - Snapshot tests on generated output so breaking changes show in diffs.
