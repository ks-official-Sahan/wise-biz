## Declined

- Revoke `UPDATE (qty, reserved)` on `inventory.stock_balances` from `wb_app` (database lane, "HIGH"): the balance upsert runs in the application role in the same statement as the ledger insert (P1-04a design), so the grant is needed. A guard trigger that only allows the balance to follow the ledger is the right hardening; tracked below.
- `claude-review.yml` author gate: assumed unnecessary because `claude-code-action` is documented to check the actor's repository permission; not verified in this sweep, so treat as open if that matters.
- Hold back later events of the same key after a failed one (`packages/events`, workers lane "HIGH"): tried and reverted. The pg bus tests and `events.md` define that a dead-letter write failure must not stall other events, and per-key order is promised only with the Kafka adapter; consumers must tolerate reordering. Revisit when the Kafka adapter lands.
- `USING (true)` SELECT policies for `wb_worker` on scheduled-job tables (database lane): accepted by ADR 0013 (read only, writes stay per tenant).
- Audit `audit_log.id` bigint identity vs UUIDv7: the id is internal to the chain order (`chain_seq` is the ordering key, `public_id` is the external one); changing a partitioned table's key is not worth the risk.

## Open (owner in brackets)

High:
- Invite email is sent inside the bus transaction (`modules/tenancy/src/consumers/invite-email.ts:83`): a commit failure resends the invite [workers].
- POS: cash rounding also rounds the card amount (`pricing-engine/src/engine.ts:349`); mid-tender price changes commit the stale price (`commit.ts:59`) [POS].
- Procurement: no batch or expiry on receipt lines, so received stock is booked with no batch and FEFO is blind (`schemas.ts:96`, `orders.ts:586`); cancel emits no event [P2-03].
- `claude-pr-review.yml`: `Read` is still allowed anywhere on the runner (for example `/proc/self/environ`) while the OAuth token is in the environment; the prompt forbids revealing secrets but nothing enforces it [infra].

Medium:
- Sign-in: a per-IP-and-email bucket (5/min) already stops one source locking an account; the loose per-email bucket (30/min from anywhere) still lets a distributed attacker block a victim's sign-in (trade-off, known since P0-08a). OTP attempts reset per challenge [identity].
- Verified NOT an issue: Better Auth 1.7.12 checks the password before the unverified-email answer (`sign-in.mjs` lines 322-338), so the 403 only reaches someone who knows the password.
- Audit anchors are still unsigned and not exported to WORM storage [P1-15].
- Worker policies: the SELECT ones are accepted (ADR 0013). Not covered by it: the outbox prune `DELETE` policy in `infra/0001` is cross-tenant [DB].
- Snapshot apply blocks the local writer queue (`packages/sync/src/pull.ts:155`); `useOnline` has no NetInfo on native; an auto-closed prior-day shift sends no close command (`shift.ts:86`, suspected) [POS].
- Digest uses the UTC date, not the branch date (`digest-job.ts:28`); export builds 1M rows in memory (`export-job.ts:218`); delivery sleeps inside a tick (`deliver.ts:84`); six lock-holding jobs share a ten-connection pool (suspected) [workers].
- nginx: no `set_real_ip_from`, so behind a load balancer every client shares the proxy's rate-limit bucket. A blanket private-range trust (tried and reverted) is unsafe because the Docker bridge gateway is inside `172.16.0.0/12`; trust one explicit load-balancer CIDR per deployment and align it with `TRUST_PROXY_HOPS` [infra].
- Infra: workflow actions pinned by tag, not SHA; `compose.prod.yaml` shares one `env_file` across services [infra].
- Console: onboarding retry duplicates, ZPL rebuilt per keystroke, command palette backdrop bounds [console].
- Procurement: `variantsExist` reads the `inventory.variant_facts` projection (a new variant can be rejected until projected) [P2-03].

Low: missing leading index on `purchase_orders.supplier_id`.
